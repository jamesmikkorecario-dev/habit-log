# AI development workflow

1. Read `AGENTS.md`, design guardrails, and relevant product/architecture documents.
2. Inspect Git status and current diff; summarize current state.
3. Before coding, identify requirements, likely files, database impact, authorization impact, test plan, and documentation impact.
4. Create a plan and implement the smallest coherent requested feature.
5. Add focused tests and run relevant verification, then the full applicable suite.
6. Update documentation when behavior, schema, boundaries, decisions, or roadmap status changes.
7. Stop without committing unless explicitly instructed.

After coding report behavior implemented, files changed, migrations, tests, exact commands, verification results, known limitations, documentation changes, and a suggested commit message.
